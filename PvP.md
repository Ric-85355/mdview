# Where Winds Meet — памятка по PvP Arena

## Билд

**Основное оружие:** Infernal Twinblades  
**Второе оружие:** Panacea Fan  
**Шанс критического удара:** 67%

---

# 1. Главный принцип

**Не атаковать постоянно.**

Основной цикл боя:

> **Наблюдение → провокация → ошибка противника → вход → короткий burst → выход → восстановление → новый заход**

Twinblades — оружие для быстрого нанесения большого урона в подходящее окно.

Главная ошибка:

> Ворваться Twinblades и продолжать атаковать до тех пор, пока противник не остановит тебя.

Вместо этого:

> **Вошёл → нанёс урон → вышел.**

---

# 2. Начало боя

Не начинать бой длинной атакующей серией.

Первые секунды использовать для изучения противника.

Нужно понять:

- часто ли он использует **Block**;

- любит ли использовать **Deflect**;

- делает ли Dodge при твоём приближении;

- атакует ли первым;

- использует ли длинные комбинации;

- какие Mystic Skills использует для контроля.

Первые секунды боя — **разведка**.

---

# 3. Защита

Есть три основных способа защиты.

## Deflect — E

Использовать, когда хорошо известен тайминг атаки.

Успешный Deflect:

- отражает атаку;

- повреждает Qi противника;

- может создать окно для контратаки.

Не нужно пытаться Deflect'ить абсолютно всё.

Особенно опасно бессистемно нажимать **E** несколько раз подряд.

---

## Block

Использовать против атак, тайминг которых плохо известен.

Особенно полезен против:

- быстрых серий;

- незнакомого оружия;

- противника, поведение которого пока непонятно.

После успешной защиты искать возможность для контратаки.

---

## Dodge

Использовать:

- против золотых атак;

- когда не уверен в Deflect;

- чтобы выйти из опасной комбинации;

- чтобы изменить дистанцию;

- чтобы подготовить новый заход.

### Простое правило

> **Уверен в тайминге → Deflect.**  
> **Не уверен → Block или Dodge.**

---

# 4. Не залипать в Twinblades

Это одно из главных правил.

После удачного входа:

1. Сделать короткую результативную серию.

2. Оценить состояние противника.

3. Если окно закончилось — прекратить атаку.

4. Выйти из контакта.

Даже если кажется, что можно нанести ещё несколько ударов.

Особенно осторожно использовать **Addled Mind**.

Эта серия отражается Deflect, поэтому против опытного игрока длинная предсказуемая атака становится опасной.

---

# 5. Когда атаковать

Хорошее окно для Twinblades возникает, если противник:

- промахнулся сильной атакой;

- закончил длинную комбинацию;

- потратил Dodge;

- ошибочно сделал Deflect;

- получил Break Defense;

- находится в Stagger;

- находится под контролем;

- потерял значительную часть Qi;

- потратил важный защитный Mystic Skill.

Тогда:

> **быстро войти → нанести burst → выйти**

Высокий шанс критического удара особенно хорошо работает именно в таких коротких атакующих окнах.

---

# 6. Когда прекращать атаку

Немедленно прекращать давление, если:

- противник снова начал стабильно Deflect'ить;

- закончилась твоя комбинация;

- противник восстановил контроль;

- заканчивается Vitality;

- противник активировал сильную защиту;

- ситуация перестала быть выгодной;

- твой HP снизился настолько, что выгоднее отступить и лечиться.

Не пытаться обязательно нанести **«ещё один удар»**.

---

# 7. Противник сидит в защите

Не атаковать Twinblades непосредственно в Block/Deflect.

Использовать **Break Defense Mystic Skill**.

Основные варианты:

### Talon Strike — Когтевой удар

Простой и надёжный инструмент пробивания защиты.

Схема:

> **Block противника → Talon Strike → Break Defense → Twinblades**

### Yaksha Rush — Якшинский рывок

Для Twinblades особенно интересен, потому что совмещает:

- быстрое сближение;

- Break Defense.

Схема:

> **Противник защищается → Yaksha Rush → Break Defense → сразу Twinblades**

Для текущего билда стоит попробовать именно **Yaksha Rush**.

---

# 8. Золотые атаки

Золотая атака обозначается характерным золотым визуальным эффектом.

Такую атаку нельзя нормально остановить обычным:

- Block;

- Deflect.

Основная реакция:

> **Dodge**

У некоторых видов оружия есть собственные золотые/unblockable Weapon Skills.

У **Infernal Twinblades собственной удобной золотой атаки нет**.

Поэтому Break Defense Mystic Skill особенно важен.

---

# 9. Serene Breeze

**Serene Breeze** — аварийный Mystic Skill для выхода из контроля.

Использовать, когда противник поймал тебя в опасную комбинацию и самостоятельно выйти из неё уже трудно.

Схема:

> **Попал под CC → Serene Breeze → разорвать контакт → восстановить дистанцию**

Не тратить Serene Breeze из-за первого пропущенного удара.

Это страховка от действительно опасной ситуации.

---

# 10. Panacea Fan

Panacea Fan позволяет делать **Reset боя**.

Если потерял много HP:

> **разорвать дистанцию → Fan → лечение → новый заход**

Не пытаться обязательно немедленно вернуть противнику полученный урон.

Лучше воспринимать один поединок как несколько отдельных коротких боёв.

### Правильное мышление

Не:

> «Мне нужно сейчас его добить».

А:

> **«Этот обмен закончен. Начинаю следующий».**

---

# 11. Mystic Skills для арены

Для текущего билда можно начать со следующего набора.

## Serene Breeze

Назначение:

**Break Control / аварийный выход из CC.**

---

## Yaksha Rush

Назначение:

**Break Defense + быстрое сближение.**

Особенно хорошо сочетается с Twinblades.

Альтернатива:

**Talon Strike / Когтевой удар.**

---

## Soaring Spin

Назначение:

- мобильность;

- защита;

- выход из плохой позиции;

- перестроение перед новым заходом.

---

## Dragon's Breath

Назначение:

- дополнительное давление;

- урон;

- Fortitude;

- продолжение удачного атакующего окна.

---

# 12. Рабочий цикл боя

Типичный бой должен выглядеть примерно так:

```text
Наблюдение
    ↓
Провокация реакции
    ↓
Ошибка противника
    ↓
Break Defense / другое окно
    ↓
Вход Twinblades
    ↓
Короткий burst
    ↓
Выход
    ↓
Fan / восстановление
    ↓
Новый заход
```

---

# 13. Чего избегать

Не делать:

- длинные бессмысленные серии Twinblades;

- атаки непосредственно в Block;

- постоянный спам Deflect;

- погоню за противником любой ценой;

- попытку немедленно отыграть потерянный HP;

- использование Serene Breeze после любого попадания;

- продолжение комбинации после исчезновения безопасного окна.

---

# 14. Тренировка на мобах

Не пытаться убивать мобов максимально быстро.

Использовать их как тренировочных противников.

Основное упражнение:

> **Ждать атаку → Block/Dodge/Deflect → 2–4 своих удара → отойти**

Даже если можно продолжить комбинацию — **остановиться специально**.

Цель — выработать привычку самостоятельно заканчивать свою атаку.

Следующий уровень:

> **защита → короткий burst → разрыв дистанции → Fan → новый заход**

---

# 15. Тренировка на боссах

Боссов использовать прежде всего для тренировки:

- Deflect;

- Dodge;

- чтения анимаций;

- терпения;

- выбора момента для контратаки.

Не пытаться победить босса как можно быстрее.

Можно провести несколько минут вообще почти не атакуя его:

> **наблюдать → защищаться → изучать тайминги**

После этого добавить короткие контратаки.

Для тренировки настоящих боссов использовать **Practice Arena** уже открытого босса.

**Boss Dummy** — деревянный столб для проверки урона и характеристик, а не настоящий тренировочный босс.

---

# 16. Главная тренировочная задача

На первых этапах не считать победы главным показателем.

Поставить себе одну цель:

> **Ни одной длинной бессмысленной серии Twinblades в защищающегося противника.**

Хороший бой — даже проигранный — это бой, в котором несколько раз получилось:

> **защитился → увидел окно → вошёл → burst → самостоятельно вышел**

Когда это станет автоматическим, следующий этап:

> **не ждать ошибки противника, а самому заставлять его ошибаться.**

То есть провоцировать:

- преждевременный Deflect;

- ненужный Dodge;

- Block;

- использование защитного Mystic Skill.

И атаковать уже после этого.
